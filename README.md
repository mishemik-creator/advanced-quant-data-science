# advanced-quant-data-science
Advanced Quantitative Research, Financial Risk Engineering, and Data Science infrastructure. 12 production-grade Python modules for time-series stationarity analytics, automated derivative pricing, matrix portfolio optimization, and multi-threaded transaction validation backed by NumPy and SciPy.
# 📊 Advanced Quantitative Research, Financial Risk Engineering & Data Science Suite

Профессиональная бэкенд-инфраструктура и комплекс математических инструментов количественного анализа. Набор из элитных модулей на Python для моделирования стохастических процессов, ценообразования деривативов, матричной оптимизации инвестиционных портфелей и автоматизированного контроля системных рисков институционального уровня.

## 🚀 Архитектурные Модули Комплекса

### 📐 Часть 1: Прикладной Квант-Анализ & Data Science
* **`live_quant_engine.py` / `btc_backtester.py`:** Движки реального времени и бэктестинга стратегий на базе Pandas DataFrames. Расчет волатильности (\(\sigma\)), коэффициентов Skewness, Kurtosis и рисков по модели Black-Scholes.
* **`quant_ols_regressor.py`:** Метод Наименьших Квадратов (OLS) на чистой линейной алгебре без использования ML-библиотек. Оценка Beta-чувствительности активов и интеграция пессимистической блокировки `SELECT FOR UPDATE` для защиты СУБД от Race Condition.
* **`time_series_stationarity.py`:** Анализ стационарности временных рядов. Вычисление автокорреляции Пирсона (Lag-1) для очистки трендов и подготовки данных к расчетам рисков VaR.
* **`portfolio_sharpe_optimizer.py`:** Реализация Портфельной Теории Марковица (MPT). Оптимизация весов капитала, расчет годовой волатильности пула и Коэффициента Шарпа (Sharpe Ratio) через векторизованное матричное умножение (`np.dot`).

### 🛡️ Часть 2: Риск-Инженерия & Оценка Деривативов
* **`credit_logistic_scoring.py`:** Логистический классификатор бинарных кредитных исходов на базе ручной реализации функции Сигмоиды. Оценка вероятностей дефолта на основе Health Factor залога.
* **`black_scholes_option_pricing.py` / `merton_default_risk.py`:** Дифференциальное ценообразование опционов Call и Структурная Модель Мертона. Вычисление справедливых рыночных премий деривативов, Расстояния до дефолта (DD) и Ожидаемой частоты дефолта (EDF) крупных DeFi-пулов.
* **`tail_copula_risk.py`:** Нелинейное стресс-тестирование хвостовых рисков портфеля через концепцию Копул. Оценка совместных экстремальных просадок (Co-Crash) и выявление неэффективности диверсификации во время рыночной паники.
* **`kelly_criterion_risk.py`:** Динамический модуль риск-менеджмента по Критерию Келли. Расчет оптимального размера логарифмической позиции (\(f^*\)) для максимизации доходности капитала на длинной дистанции и защиты от риска разорения.

### 🔮 Часть 3: Теория Информации & Стохастические Процессы
* **`bayes_quant_model.py`:** Байесовский обновляемый алгоритм предсказаний. Пересчет условных вероятностей (\(P(A\vert{}B)\)) и обновление априорных рыночных убеждений на основе поступающих потоков данных.
* **`markov_chain_model.py` / `hidden_markov_regimes.py`:** Марковское моделирование режимов рынка. Расчет матриц переходных вероятностей, поиск стационарных состояний систем и декодирование скрытых фаз волатильности (Сон/Шторм).
* **`kalman_filter_arbitrage.py`:** Рекурсивный одномерный Фильтр Калмана для высокочастотного HFT-арбитража. Мгновенная очистка ценовых рядов от рыночного шума стаканов и динамическое обновление спреда по принципу "Прогноз-Коррекция".
* **`shannon_entropy_analytics.py`:** Измерение степени хаоса и информационной неопределенности в Prediction Markets по методу Энтропии Шеннона в битах.
